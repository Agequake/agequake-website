## 経営理念（MVV）

・Vision（目指す未来）: 地域から、未来のモデルを創る。
・Value（行動指針）:
  1. 課題の奥にある本質を見る

5. 経営数字（単価・リピート率・店販売上）の改善

商品販売そのものではなく、上記を一体提供する「コンサルティング」が事業の本質。

## HP・LPコピーライティングの考え方（営業理論からの応用）
※出典: 営業トーク理論まとめ（生保営業向け教材）。保険営業の手法そのものではなく、
HP・LPの「文章構成」「言い回し」に応用できる考え方として整理。新規LP作成・既存LP改善時の参考にする。

・問題提起の構造
　「あるべき姿」と「現状」のギャップ＝問題。多くの人は問題に気付いていない。
　→ HPでは「気付いていない問題」を先に提示し、気づき→解決策（Agequakeの仕組み／整巡湯）の順で構成する。
　（lp-shinkyu.htmlのFV〜中盤の流れがこの構造に対応）

・hub理論（共通項を起点に本題へ誘導）
　相手が元々関心を持っているテーマ（顕在ニーズ）を共通項（hub）にして、
　本来伝えたい話（潜在ニーズ・経営課題）へ自然につなげる。
　→ HPの冒頭は「値上げが怖い」「客単価が伸びない」など院長が既に気にしているテーマから入り、
　そこから整巡湯・仕組み化の話につなげる。

・疑問の技術（疑問→答えの順で構成）
　伝えたい情報を「答え」として提示する前に、まず読者の中に「疑問」を作り込む。
　→ 見出し・キャッチコピーは断定文ではなく問いかけ調にし、本文・解決策セクションで答える構成にする。
　（例：「なぜ、腕を上げるほど値上げが怖くなるのか。」）

・争点定義理論（比較の判断基準を自社が有利な軸で設定）
　「何を基準に選ぶか」という争点（判断基準）を提示し、相手の同意を得る。
　基準そのものを自社の強みに合わせて設定することで、比較で優位に立てる。
　→ 「価格」ではなく「院外接点の有無」「リピート導線の有無」など、Agequakeが強い軸を判断基準として提示する。

・そうですよね話法／かもしれない話法（反発を避ける言い回し）
　断定・押し付けにすると反発されやすい。「〜ですよね」「〜かもしれません」のような
　共感・仮定のトーンにすることで抵抗感を下げる。
　→ HPの文章は「〜すべきです」ではなく「〜ではないでしょうか」「〜かもしれません」のような表現を基本にする。

・ゴールベースドコンサルティング（理想像から逆算する）
　現状の課題からではなく、まず「理想の状態（ゴール）」を見せ、そこに至る手段として提案する。
　→ HPでは「値上げできる院」「院外接点がある院」といった理想の院の状態を先に示し、
　その手段としてAgequakeのコンサル・整巡湯を提示する。

・テストクロージング（仮定で前に進める）
　「仮に〇〇だとしたら」という仮定の話として進めることで、相手に心理的負担をかけずに次の段階へ促す。
　→ CTAは「お申し込みください」ではなく「まずは無料サンプルを試してみてください」など、
　仮定・お試し前提の言い回しにする（既存CTA文言と方向性は一致）。

・紹介入手の構造（満足度→紹介導線）
　契約者の満足だけでなく「話を聞いて良かった」という納得感が紹介につながる。
　→ 院長の声（お客様の声）セクションは、商品の良さだけでなく
　「導入して気づいた点」「やってよかったと思える理由」を語ってもらう構成にする。
　将来的には紹介・口コミ導線（紹介キャンペーン等）の検討材料にする。

## デザイン・実装方針（決定事項）

- 配色: ネイビー（#0d1b2a / #1a1a2e / #0f3460 のグラデーション）＋ゴールド（#c9a84c）＋クリーム（#faf8f3）。
- フォント: 見出し系にCormorant Garamond（Google Fonts）＋和文は既存のYu Mincho/Noto Serif JP系。
- 画像最適化: Pillow（`from PIL import Image`）でリサイズ＋JPEG再エンコード（quality 75-82）が標準ワークフロー。
- 画像の埋め込みは「別ファイル＋`loading="lazy"`」方式を採用（base64埋め込みではない）。同一オリジンなのでリクエスト数増加の問題は小さく、キャッシュ・Lighthouse的に有利という判断をユーザーに説明済み・了承済み。
- Hero Slider（ヒーロースライダー）パターン:
  - `.hs-slide` / `.hs-slide.is-active` のトグルで切替
  - `setInterval` による自動再生（5000ms）
  - フェード切替（`opacity`/`visibility`）
  - `prefers-reduced-motion` に対応
  - 矢印・ドットでの手動操作＋`restartAutoplay()`
- セクション背景画像パターン（`.sec-with-image` / `.sec-image`）:
  - 元はFVの`.fv-bg`パターン（フルセクション背景＋斜めグラデーションオーバーレイで画像を薄く見せる）を、各セクションに展開したもの。
  - セクションに`sec-with-image`クラスを追加し、本文を`.sec-text`（`max-width:720px`）で囲み、最後に`<div class="sec-image" style="background-image:url('...');" role="img" aria-label="...">`を追加する。
  - `.sec-image`はセクション全体に`position:absolute; inset:0`で重なり、`::after`の`linear-gradient(100deg, ...)`でテキスト側を不透明に、反対側を薄く見せる。
  - オーバーレイ色はセクション背景色に合わせて上書きする: `.sec-light`系は白系（デフォルト）、`.sec-dark .sec-image::after`はネイビー系、`.sec-seizyunto .sec-image::after`はクリーム系（`#faf8f3`〜`#f2ead8`）。
  - モバイル（max-width:768px）では`.sec-image { display: none; }`で非表示。
  - 適用例: Section01（`lp-shinkyu-hero.png`）、Section04（`lp-shinkyu-market.jpg`）、Section05（`lp-shinkyu-seijunto-scene2.jpg`）。
