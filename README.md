# AgeQuake

AgeQuake のコーポレートサイト（静的HTML）です。

【本番URL】
https://agequake.jp

GitHubへPush後はNetlifyへ自動反映される。
変更作業時は本番環境への影響を考慮すること。

## ローカルでの確認方法

PowerShell で以下を実行するとローカルサーバーが起動します。

```powershell
.\serve.ps1
```

デフォルトでは `http://localhost:3000/` で配信されます。ポートを変更する場合:

```powershell
.\serve.ps1 -Port 8080
```
